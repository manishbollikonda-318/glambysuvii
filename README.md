# Glam By Suvii Unisex Salon

A next-generation, mobile-first web platform for **Glam By Suvii Unisex Salon** located in Tellapur, Hyderabad.

## Features
- **Mobile-First & Symmetric UX**: Ultra-smooth, responsive UI tailored for mobile devices.
- **WhatsApp Slot Booking Engine**: Interactive calendar powered by FullCalendar with real-time slot selection and instant WhatsApp redirection containing complete appointment details.
- **Embedded Location Map**: Interactive Google Maps integration with operating hours and direct navigation links.
- **Salon Inquiry Section**: Direct inquiry form with WhatsApp integration and DPDP Act 2023 compliance.
- **Serverless API**: Netlify Functions backend (`/api/*`) for webhooks and click-to-call integration.

## Tech Stack
- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS v4, Framer Motion, Lucide Icons, FullCalendar
- **Backend**: Express.js, Netlify Functions (`serverless-http`)
- **Compliance**: DPDP Act 2023 consent mechanisms
